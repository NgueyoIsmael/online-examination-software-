DEPLOY ON VERCEL - short version (full steps are in the chat)

1. Copy everything from this zip INTO your project folder (Replace when asked).
2. Create an empty MySQL/MariaDB database online, then import sql/full_database.sql into it.
3. Put the project on GitHub (do not upload logs/ or any password).
4. On vercel.com: Add New > Project > import the GitHub repository. Framework preset: Other.
5. Before deploying, add these Environment Variables:
     DB_HOST  DB_PORT  DB_NAME  DB_USER  DB_PASS   (and DB_SSL = 1 if your provider needs it)
     CERT_SECRET = any long secret text
     APP_DEBUG = 1        (only while testing, then delete it)
     MAIL_ENABLED=1 MAIL_HOST MAIL_PORT MAIL_USERNAME MAIL_PASSWORD MAIL_FROM   (for emails)
6. Deploy, then open  https://YOUR-SITE.vercel.app/__health  to check everything.
7. Open https://YOUR-SITE.vercel.app/auth/admin_login.php, log in as admin / admin123
   and change the password at once. Then delete APP_DEBUG and redeploy.

Your local XAMPP version keeps working with these files.
